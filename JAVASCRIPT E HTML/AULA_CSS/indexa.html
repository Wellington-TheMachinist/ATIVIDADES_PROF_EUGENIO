Objetivo Central

Demonstração prática de uma infraestrutura de rede heterogênea, integrando servidores corporativos e dispositivos IoT em um ambiente controlado.

Arquitetura e Componentes da Rede

Servidor Principal

Windows Server

  • Gateway da Rede.
  • Serviços DHCP e DNS.
  • Hospeda a Landing Page principal (Esta página).
  • Oferece Serviço HTTP (IIS) para clientes.

Ponto de Acesso (AP)

Roteador Desativado

  • DHCP desativado (atribuído pelo Servidor).
  • Serve como Ponto de Acesso (AP) principal (Wi-Fi).
  • Opera também como Switch LAN para dispositivos cabeados.

Dispositivo de Borda (IoT)

Arduino (Conexão via LAN)

  • Conectado diretamente ao Switch/Roteador.
  • Oferece um serviço HTTP de teste.
  • Demonstração de integração cabeada de IoT.

Servidor Web Sem Fio

ESP32 (Conexão via Wi-Fi)

  • Conectado à rede Wi-Fi do Roteador/AP.
  • Oferece páginas HTTP demonstrativas.
  • Valida a conectividade sem fio com o Servidor.

Fluxo de Comunicação Simplificado

O projeto demonstra a comunicação de clientes e dispositivos IoT através de serviços essenciais, roteados pelo Servidor Windows.

1. Cliente/Notebook → Conecta-se primariamente via Wi-Fi (Roteador AP) e recebe IP do Windows Server (DHCP).

2. Resolução de Nomes → Utiliza o Windows Server (DNS) para consultas.

3. Acesso IoT → Clientes acessam Arduino (LAN) e ESP32 (Wi-Fi) para visualizar suas páginas HTTP.
